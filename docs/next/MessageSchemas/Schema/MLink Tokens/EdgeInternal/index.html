EdgeInternal

#Message NameDescription
7943CntrlModelFeatureSpeccontrol: the model kernel's feature specification - one row per input column, as data

Authored centrally and served through the Edge MLink pair. The kernel composes its input row from this table and

stamps featureSchemaHash (a hash over the rows in colIndex order) on every capture, so a row file and the spec that

produced it never disagree. A column is one operator over one field of one lane, in one form, with an optional

reference lane and field for the relative forms; tauSec is the operator's time constant where it has one. The

operators are named here and implemented in the kernel; this record does not describe their internals.
7944CntrlModelSetcontrol: the promoted head set for one model tier, as data

Authored centrally and served through the Edge MLink pair. The controller loads the weights the rows name

from the local store and checks each weightsHash; a set whose specCode or featureSchemaHash is not the

kernel's is refused. modelSetHash is over the rows in outputIndex order and is the value every model frame

and mandate carries. laneCount is the summation lane count the weights are normative under; a host or card

that sums in a different order does not reproduce the set.
7942CntrlModelUniversecontrol: the day's model universe for one edge box - roots, expiries, benchmarks, tiers, alignment

Authored centrally before the open and served through the Edge MLink pair. Every writer of the model

kernel's table (the controller, the feed handlers, the cores) derives the same dense-id map from this

record and stamps mapHash on what it writes; the kernel refuses a writer whose hash differs. Tier 0 roots

are the benchmarks, accumulated before their dependents. liquidExpiry names the root-expiry whose

surface state feeds the stock row. An intraday row addition admits a root or expiry with the settle

delay; nothing outside the record is parsed past the header at the feed.
9508EdgeBucketMandateAckedge-to-gateway: bucket mandate admission and state

Sent on every state change of a bucket mandate and as a periodic status (statusIntervalMs). Held =

accepted but no live orders because a required source (underlier feed, model frame) is unmet or

the underlier band is breached; Pulled = a kernel trip or traded-cap stop latched the scope.

Per-child acks and executions still flow as EdgeOrderAck (9503) / EdgeExecution (9505) with

parentNumber = bucketNumber.
9541EdgeCoreControlcontroller-to-core (orders.hot): operator verbs - COMMANDS, ordered and acknowledged

Mode follows the RouteControl vocabulary used by EdgeExchSession (9522): Enabled quotes,

SafeMode manages the existing order set but opens nothing new, Disabled pulls and idles.

Drain = SafeMode then Stopped once the order set is flat; Halt = pull everything now.

commandId is monotone within the controller epoch; the core applies commands in commandId order,

acks each on EdgeCoreControlAck, ignores a stale epoch, and clears a Halt only on a ResetAllLatches

or Drain whose commandId exceeds the Halt's. Reductions are applied before increases.
9542EdgeCoreControlAckcore-to-controller (events.hot): one ack per command (EdgeCoreControl, EdgeExchSession/Reset,

EdgeKernelLimits, EdgeTradedCapLevel, EdgeKernelReset all carry a commandId)

Applied = in force; Ignored = stale epoch or lower commandId than one already applied; Rejected =

malformed or not permitted in the current core state (reason in detail). A command without an ack

within cmdAckTimeout is a controller alarm and blocks dependent commands (e.g. a grant increase

waits for the preceding reduction's ack).
9540EdgeCoreStatecore-to-controller (also published: the tooling view of the Rust core)

Sent on every state change or otherwise every 15 seconds. One row per core instance.

epoch is minted by the controller at each core launch; every ring frame and every

crossing record carries it, and a frame from another epoch is dropped on both sides.
9545EdgeCoreStatscore-to-controller (events.cold; also published) - sent every 15 seconds

Lane and hot-loop health. Lag = MMR head seq minus consumed seq at sample time; gaps are seq

discontinuities seen by the core as reader; latencies are the core's monotonic-clock

measurements, in nanos.
9633EdgeEngineStatscore to controller (events.cold; also published): the quoting engine on one name and venue, every second

The slow controller's inputs: what each action earned, the latency the take side raced at, and the

parameters in force when it did. Fills are shares by the action that placed the order; markouts are

realized against the fair at the two horizons, summed over the period's fills. Dollars fixed 1e4.
9522EdgeExchSessionrisk-to-edge
9524EdgeExchSessionAckedge-to-risk

sent on every state change or otherwise every 60 seconds
9630EdgeFeedStatsfeed handler to controller (events.cold; also published): one receive queue of the GPU feed handler, every second

EdgeProducerStatus (9583) says whether the handler is alive; this says which queue is starving and what the

universe gate is doing. NIC drops and completion-queue backlog are the ingress-loss levers; gate counts are

the filter's work; wire-to-slot is the handler's own latency, NIC timestamp to slot written. Counters are

cumulative since the producer epoch started.
9560EdgeKernelLimitscontroller-to-core (the inner risk ring: the speed bump)

Windowed caps the core enforces per (session, underlier) over fixed windows of 1s, 10s, 60s

and 300s. Pure integer arithmetic on ring-buffer sums; no policy, no records, no joins - the

policy that produces these numbers lives in the controller. A row with an empty undKey is the

session default; a row with an undKey overrides it for that underlier. 0 = no cap on that cell.

Exceeding a cap latches the (session, underlier) - quotes pulled, new entry blocked - until

an EdgeKernelReset (or EdgeCoreControl ResetAllLatches) clears it.
9562EdgeKernelResetcontroller-to-core (operator verb; pattern of EdgeExchSessionReset 9523)

Clears a kernel latch. A reset never raises a cap and never advances a traded-cap level:

if the condition that tripped is still true the core re-trips on the next event, which is

the intended behaviour (the operator raises limits through EdgeKernelLimits / the controller

advances EdgeTradedCapLevel, then resets).
9561EdgeKernelTripcore-to-controller (also published: the audit trail of every speed-bump action)

One row per trip event; tripNumber is monotone per core epoch. Warning rows (action=Warn,

latched=No) precede a trip when EdgeTradedCapLevel.alertFrac or a soft fraction of a

kernel cap is crossed, so operators see the approach and not only the stop.
9636EdgeReflexEventreflex to core (reflex.evt; also archived): one event on a held message - held, released, discarded, failed closed

The core's ledger and journal are built from these: a Released event is the moment an order left the box, with the

hardware timestamp of the driver packet that fired it and of the transmitted frame, and the TCP and application

sequence numbers the reflex stamped. The host stack follows these events into its retransmission queue.

Sequence-continuous per engine and epoch; a gap is a reflex fault.
9565EdgeRiskHeartbeatrisk-control-server liveness for edge controllers that take their control set over MLink

The risk-control server is a pure bus service: it publishes the control set (9522 / 9541 / 9560 /

9562 / 9563) as desired state and this beat; an edge controller receives both through its Edge

MLink session. Three missed intervals = controller dead-man: the controller drains its core exactly

as a dropped control session did. The MLink session state covers the MLink server only.
9634EdgeStockVenueDetailreference: one equity venue's fees and matching rule as the engine's cost comparisons need them

Authored centrally, served through the Edge MLink pair. Dollars per share fixed 1e6 (3000 = $0.0030). The

engine reads its costs from this record and never from a constant; a fee tier change is a new row with a

new effectiveDate. bboFeedCode names the venue's own top-of-book feed, the one the box next to it parses.
9563EdgeTradedCapLevelcontroller-to-core (the middle risk ring: a day-cumulative traded-contracts lease)

A GRANT under the conservation invariant (reconciled consumption + outstanding grants + unresolved

exposure <= allowance, per account and risk dimension). Working + pending + uncertain exposure is

ALWAYS reserved against the level (no optional form). A grant is tied to the core epoch it was

issued for (grantEpoch); a core in Recovering holds no grant and increases no risk.

The controller computes level = reconciled traded so far + headroom step and pushes it on a

schedule or when consumption crosses a fraction of the remaining headroom. Levels are

MONOTONE within a trade date; the only decrease is Halt, which sets level = traded (a hard

stop at whichever enforcer holds it). The core enforces every level itself; where the venue

supports an equivalent control (Pillar Risk Admin session) the core's venue adapter mirrors

it and reports the exchange state on EdgeTradedCapStatus.

Scope: Session and SessionRoot are enforceable by the core alone (it sees every fill on the

session); Member and MemberRoot span sessions and are computed by the controller/gateway -

the core enforces its session slice and mirrors the member level to the venue where possible.
9564EdgeTradedCapStatuscore-to-controller (also published)

Sent on every level change, every trip, and otherwise every 15 seconds. Carries BOTH the

core's own traded count and the venue-acknowledged level so the controller can alarm on

drift between the two, which is a direct check on the fill path.
9629EdgeVenueDetailreference: one options venue's matching rules as the model and the tactic need them

Authored centrally, served through the Edge MLink pair. The allocation model decides how a resting order

is filled at a level: PriceTime (first in line takes the print), ProRata (size share), Hybrid (a

priority allotment then pro rata). The mask bit ties the venue to the participant bitmasks on

OptSeriesMarket (9594).
9624OptSeriesStaticstandardized model input: day-static descriptive data for one option series

Assembled centrally once a day, served through the Edge MLink pair, written by the controller into the

slow region of the model kernel's table. Values are as of the prior close.
3645PricingGrid
9604QuoteDecisioncore-to-controller (journal lane) -> ArchiveHost: one row per tactic decision that emitted a command,

and per TURN / NOSHOW / PULL decision including suppressed ones

The measurement-integrity record: state, action and propensity at decision time, sequence-continuous

per engine so completeness is checkable (a gap in seq marks a censored period; off-policy evaluation

excludes it). Lossless: journal lane, never events.cold. Prices fixed 1e4, probabilities fixed.4.
9623UndStaticstandardized model input: day-static descriptive data for one underlier

Assembled centrally from the Complex object once a day, served to the edge through the Edge MLink

pair, and written by the controller into the slow region of the model kernel's table. Values are

as of the prior close; tradeDate says which.

SRParentOrder

V8 Message Definiton

Parent orders received via FIX, SRSE, SpiderRock GUI tools, or third-party vendor systems are all visible in this table immediately after receipt. Parent orders can be for stocks, futures, options, or spreads, and can be one-sided (agency) or two-sided (facilitation). Records are immutable (no updates) and are published to the SpiderRock elastic cluster on arrival.

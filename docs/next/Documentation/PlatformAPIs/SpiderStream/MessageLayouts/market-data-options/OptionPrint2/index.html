Layout: OptionPrint2 (ID: 2805)

One record per active option series, replaced by each new print, so the record always holds the latest trade. Same print as OptionPrint without the quote markup; adds volume broken out by trade type (ISO, SLA, MLA, cross, floor, multi-leg, unknown) and total volume.

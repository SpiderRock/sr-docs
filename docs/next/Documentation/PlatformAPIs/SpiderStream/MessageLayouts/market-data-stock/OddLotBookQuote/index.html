Layout: OddLotBookQuote (ID: 3080)

Carries odd lot quotes, which are excluded from the round lot NBBO in StockBookQuote. This table contains live equity quote records for all CQS/UQDF securities as well as US OTC equity securities, SpiderRock synthetic markets, and a number of major indexes. Each record contains up to two price levels and represents a live snapshot of the book for a specific market.

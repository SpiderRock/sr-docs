Citrix Tool Shortcuts

Keyboard and mouse shortcuts for the Citrix Tool Suite, grouped by tool. Shortcuts that work in every grid are listed first.

All Grids​

All grids in the following tools use the shortcuts below: Order Manager V1 (OMv1), Risk Manager (RM), Risk Viewer (RV), Hedge Tool (HT), Trade Analyzer (TA), Risk Analyzer (RA), Control Viewer (CV), SM, and AV.

ShortcutAction
Ctrl-ASelect the entire grid
Ctrl-NClear selection
Ctrl-DExtend selection: columns (the entire columns where at least one cell was already selected will be selected)
Ctrl-FExtend selection: rows (the entire rows where at least one cell was already selected will be selected)
Ctrl-CCopy selection to clipboard

Symbol Viewer (SV)​

Main Window​

ShortcutAction
Ctrl-Up / Ctrl-DownSets focus to the account entry combobox and cycles the account from the recent list
Ctrl-~ / Ctrl-Shift-~Cycles the account from the recent list without setting focus to the account entry combobox
Alt-~ / Alt-Shift-~Cycles the account from the custom account sets list (defined in the picker) without setting focus to the account entry combobox
Ctrl-TSets focus to the symbol entry box. This is redundant for the majority of symbols, since typing any letter (A–Z) sets focus to the symbol entry. However, users can't do the same for future symbols that start with @, because Shift-2 is a different shortcut that has a higher priority
F5Sends a Refresh request (same as clicking the Refresh button)
EscClears test positions, clears market overrides, and sends a Refresh request
F6Creates an option blotter closing order using the position columns
F7Creates an option blotter closing order using the test columns
Ctrl-ASelects all the grid cells
Ctrl-DSelects all the columns where at least one cell is selected (expand columns)
Ctrl-FSelects all the rows where at least one cell is selected (expand rows)
Ctrl-CCopies selected grid cells to clipboard
Ctrl-WToggles weekly option selection (same as checking "Weekly" in the Main Menu popup)
Ctrl-SOpens the Main Menu popup in the center of the main window
Ctrl-PCreates a debug screenshot (saved as a PNG in the log folder) and a settings snapshot. Users are encouraged to use this option instead of system screen capture tools
1 – 6Opens the Option Blotter with the current selection and applies preset 1–6
Ctrl-BOpens a blank Blotter
Ctrl-LOpens a blank pair trade dialog
Shift-1 – Shift-6Opens the Multileg Blotter with the current selection and applies preset 1–6
F1 – F4When SRLink commands are defined in the Main Menu, invokes commands 1–4 (sends out ULinkContext messages). Same as clicking the F1–F4 toolbar buttons
Holding Ctrl when double-clicking one of the order columns (market price, vol)When immediate orders are enabled (Main Menu), sends an immediate order using a Quick Ticket (option QT from the risk grids, spread QT from the spread grid) and the preset defined in the Main Menu

Account Entry Combobox​

ShortcutAction
PgUp, PgDownOpens the account picker

Account Picker​

ShortcutAction
Ctrl-FMoves focus to the filter box

Expiration Panel​

ShortcutAction

Order Dialogs​

ShortcutAction
Ctrl-Shift-1 – Ctrl-Shift-6Saves preset 1–6
Ctrl-1 – Ctrl-6Applies preset 1–6

Quick Order Dialogs​

ShortcutAction
Ctrl-BSends a buy order
Ctrl-SSends a sell order

Order Blotter​

ShortcutAction
Ctrl-ASelects all the history grid rows
Ctrl-VImports orders from clipboard
Ctrl-NCreates a new blank order page (tab)

Option Blotter​

ShortcutAction
Ctrl-QApplies market bids to buy orders
Ctrl-RApplies market asks to sell orders
Ctrl-WApplies market bids to buy orders and asks to sell orders

History Grid​

ShortcutAction
+ / -Modifies the selected option or stock order by increasing/decreasing the limit price by the tick (or the limit vol for option vol orders)
Holding Shift while restoring an orderSwitches the global main symbol to that order's symbol
Holding Ctrl while restoring an orderCreates an order with a new risk group ID (essentially copies an order)

VolTerm Chart​

ShortcutAction
CtrlToggles the x-axis labels between years and dates

Custom Events Dialog​

Date spinner

KeysAction
No control keysIncrease/decrease day
Holding Ctrl or ShiftIncrease/decrease month
Holding both Ctrl and ShiftIncrease/decrease year

Move spinner

KeysAction
No control keysIncrease/decrease by 0.1%
Holding CtrlIncrease/decrease by 0.01%
Holding ShiftAll the rows' Move values will increase/decrease simultaneously

Chart Tool (CT)​

General​

ShortcutAction
Ctrl-TSets focus to the Symbol 1 entry field
Ctrl-YSets focus to the Symbol 2 entry field
Typing a letterIf none of the symbol entries are focused, typing a letter sets focus to the Symbol 1 entry field and adds the first letter (i.e., to set Symbol 1, the user just types it regardless of which control has current focus)
Ctrl-1 – Ctrl-9Switches to preset 1–9 (same as clicking a preset button in the upper-left preset toolbar)
F1 – F8Sets the time range (horizontal axis) to 3M, 6M, 1Y, 2Y, 3Y, 4Y, 5Y, All, respectively
Ctrl-SToggles the visibility of the preset editor pane
Ctrl-HToggles the visibility of the histogram

Chart Area​

ShortcutAction
Mouse right-clickSets a custom horizontal gridline, erasing previously added custom gridlines
Holding Ctrl while right-clickingAdds a new custom horizontal gridline without erasing previously added ones
Shift-right-clickOpens an editor (spinner) that lets the user set a custom horizontal gridline by entering an exact Y-axis coordinate. The editor is pre-populated with the clicked Y-axis value
Holding Ctrl while Shift-right-clickingOpens the same editor; holding Ctrl prevents the user from erasing previously added custom gridlines
Ctrl-E / Ctrl-ROpens the custom value editor with the mid-axis value populated (left or right from center)
EscClears all the custom gridlines
Ctrl-ZZooms vertically: sets the Y-axis range to the outer custom gridlines in the upper chart (at least 2 gridlines should be set prior to that)
Ctrl-Alt-ZSame as Ctrl-Z, for the bottom chart
Ctrl-XRemoves the zoom from the upper chart
Ctrl-Alt-XSame as Ctrl-X, for the bottom chart
